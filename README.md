# Pagination Patterns / Padrões de Paginação

Offset and cursor pagination examples for APIs.

Exemplos de paginação offset e cursor para APIs.

## English

Prefer cursor pagination for large/changing datasets; offset is fine for admin UIs and small lists.

## Português

Prefira paginação por cursor em datasets grandes/mutáveis; offset serve para UIs admin e listas pequenas.
